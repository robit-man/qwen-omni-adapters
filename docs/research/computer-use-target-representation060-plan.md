Bounded hypothesis: remove generated character arithmetic and represent only
meaningful selector alternatives. The model copies a label or prefix from the
original intent; host code computes its exact, unambiguous source binding.

on a stronger post-generation decoder. Keep kind and label separate through
model interpretation. Do not strip keywords, repair arbitrary aliases, ignore

they must not silently bind to the first occurrence. Check the native parser's
support for the chosen schema before the one actual evaluation.

labels containing role words, Unicode, repeated text, explicit prefixes,
