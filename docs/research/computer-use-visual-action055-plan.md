## Failing criterion and hypothesis

The actual GPU1 pilot returned false coordinates for both absent targets.
Semantic reading and coordinate production are also coupled to the same MD
producer in the current surface/store/policy. The visual planner receives a
textual account without the captured image. Strict whole-PNG equality still
blocks input on irrelevant rendering changes. P054 fixed read-only perception,
not any of these action boundaries.

Separate source-bound Omni semantic assessment from MD coordinates, provide the
actual captured image to Omni planning, and require a latest-frame assessment
of the exact target at the fixed point before Kev selects an input. This is one
coherent action contract, not a single producer-equality deletion.

## Implementation ownership

- `visual_semantics.py` and tests: existing adapter describe image transport,
  closed JSON assessment decoding, separate logical-model/manifest producer pin.
- `visual_surface.py`, `visual_policy.py` and tests: immutable semantic,
  coordinate and latest-frame receipts, separate pins, canonical host registry,
  finite Kev selection and guarded physical dispatch.
- Root: store/app/planner integration and integration tests. Only the trusted
  server factory chooses endpoint, producer and action contract. The planner
  supplies an objective, target description and supported verb, never coordinates
  or receipt construction.
- Independent verifier: frozen acceptance and source-forwarding addendum,
  counterexamples, actual model grading and requested effect.

Strict v1/native behavior remains the default. The new condition is explicitly
selected through trusted `OMNI_NATIVE_VISUAL_CONTRACT=model_revalidated_point_v1`
for its evaluated adoption. A semantic-client configuration failure must not
preempt a valid native observation, nor silently permit v1 visual input.

Planning preserves the adapter's semantic-text boundary: the exact image goes
to image comprehension, whose untrusted reading goes with the original goal
to language planning. The language stage does not directly see pixels. The
separate semantic target/point requests retain both exact image and intended
target. Task-directed whole-scene extraction is not implemented by this change.

Negative latest-point validation retains all completed semantic, grounding and
latest-frame receipts in controller feedback. Returning only a rejection code
would lose the information needed for an informed recovery.
