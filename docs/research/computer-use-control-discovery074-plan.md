## Bounded hypothesis

Compression currently has no typed path to expand an omitted current native
control. Historical observation recall stores text, not missing current bindings.
A task-local, bounded, nonauthorizing index of actually observed controls plus an
explicit read-only expansion operation can restore that path. The planner first
chooses an opaque discovery reference; the host obtains a fresh observation and
prioritizes that exact observed identity using the existing projection mechanism.
Only the subsequent fresh full node may participate in normal action selection.
This hypothesis does not assert that discovery alone fixes arbitrary planning.
