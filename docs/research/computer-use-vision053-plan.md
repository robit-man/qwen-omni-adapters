## Required design

1. Preserve current native behavior whenever native evidence is valid. Record
   unavailable native capabilities explicitly; never fabricate native labels,
   enabled/sensitive state, text values, selection or successful write effects.
2. A separate visual observation binds the exact task-authorized foreground XID,
   host PID/start/UID, registered base or proved direct transient, geometry and
   captured frame. Foreign/unknown scope, cancellation and identity/protocol
   failures stay fail-closed. A stale native target never silently becomes a
   different visual target.
3. Route a source-bound current image to the visual layer. Preserve producing-
   tool authority and historical/current distinctions. Omni owns task intent;
   Kev ranks finite grounded alternatives or abstains; pinned Moondream 3.1
   supplies visual observations/points; the host owns physical dispatch.
4. Reuse existing finite-point, exact-frame, geometry, scope, cancellation and
   single-dispatch guards. Preserve known protected/disabled native exclusions.
   Unknown semantic capability is not a positive semantic permission or effect.
5. Inspect visual results as untrusted evidence. A dispatched pointer/key or a
   changed screenshot does not establish task completion. Exact writes and saved
   artifacts need their appropriate independent readbacks. Uncertain input stays
   recorded until reconciled and must not be blindly repeated.
6. Keep pointer, double/right click, selection/drag, scrolling, keyboard and text
   entry explicitly tracked. An initial inspection/point milestone does not
   complete the full desktop-use requirement.
