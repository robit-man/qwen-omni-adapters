# Packaged native long-horizon task specifications

This directory contains **100 unrun task specifications**, across the 16
families in `docs/computer-use-long-horizon-evaluation.md`. Ready: **0**.
Executed: **0**. Passed: **0**. The 200 Qwen/Ornith first-attempt cells are planned
only. The user has authorized the evaluation; technical readiness is not a new
permission step. Earlier LH001 pilots are separate historical diagnostics.

`runtime.verify_long_horizon_native` provides the portable foreground text/native
runner; see `docs/computer-use-long-horizon-runner.md` for setup, evidence and
grading. CPU harness tests do not count as executed task cells.

Read `matrix.md` for the task inventory, `tasks.json` for complete goals,
declared fixture content, exact output paths and criterion specifications,
`protocol.json` for the proposed native-only condition, and
`primary-source-registry.json` for inspiration and source snapshot hashes.
`manifest.json` hashes the complete packaged design data and retains its
original design-manifest digest. Package integrity and CPU controls are not
live task results.

Coverage is substantive office/research work: versioned migration decisions,
group/venue constraints, twelve-session schedule repair, kit arithmetic and
compatibility, six-object catalogues and rights, confidential-field separation,
eighteen-document reconciliation, ten exact edits across three drafts, mixed
units and real charts, official tutorial transfer, four-document packets,

six-clip player persistence, recovery conditions, and twelve-record/six-asset
capstones. Tasks within a family are correlated variants, not 100 independent
workflow algorithms. Report task and family aggregates separately.

The package declares 454 inline input-file specifications, including 100 public
task briefs, and 36 additional owned
media assets, 960 mandatory outcome/method checks, 79 memory followups and eight
controlled amendment/window-interruption cases. None was materialized or run.
All source acquisition by the solver must use actual native browser GUI and
visible relevant sections. Candidate official starting URLs are not verified
page/content pins; freeze them before any run. The saved benchmark research is
protocol inspiration, not an inherited score or official task/evaluator.

Readiness is false because these exact host prerequisites have not been proved,
not because a task must already succeed before it can be attempted. The runner
materializes declared inline inputs, validates frozen source evidence and checks
every new blank application's native accessibility. Complete predeclared rubrics
satisfy rubric readiness; pending independent semantic grading does not prevent
transport. Fourteen media/controlled-event cases still need materializer or
injector implementations. Other 86 tasks have a conditional setup/transport path,
which is not a claim of host readiness or full workflow support. Ordinary clients
do not yet select mandatory native-task compilation automatically.
Egg31's Flatpak identity gap and Egg41's active Chromium null-child observation
failure remain explicit host blockers; these specifications do not repair them.

Only deliver `goal_text` and the declared input artifacts to a future solver.
**Never send the whole task object, sealed evaluator section, builder, oracle
pack, precomputed answers or action procedure.** Setup may open blank owned
applications and create declared inputs, but may not navigate sources or write
requested outputs. The solver owns all subsequent GUI work. The controlled
perturbation cases require a separately proved, predeclared input/event injector;
they do not permit arbitrary operator assistance.

Every task requires independent saved-artifact readback and reopen evidence,
actual guarded keyboard and physical-pointer receipts, exact owned identity and
preservation checks. Archive membership, formula/chart structure, confidential
canaries, protected spans, revision authority, source semantics and memory
readback are graded where applicable. A model claim, file existence, exit code,
configured auxiliary model, old successful receipt or primitive pass is
insufficient. Preserve every setup failure, unresolved input and unsuccessful
attempt; do not silently remove blocked cases from the intended denominator.

No network access, browser/model requests, desktop inputs, dependency installation
or GPU/service lifecycle actions were performed to package this suite or test its
runner. The isolated harness adds no production controller behavior. Every task
brief supplies public source URLs/topic labels and frozen delivery conditions,
without sealed answers. All 75 archive cases have exact member/byte checks;
the six reconciliation cases check the authoritative Current set; the six
editorial tasks have an automatic exact full-text diff oracle. Remaining
unproved semantic/layout/reopen criteria stay pending independent grading.
