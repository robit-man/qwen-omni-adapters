# Voice references

`female_voice.wav` is the primary Female preset and active default. It is a
metadata-free 16 kHz mono PCM16 conversion of the repository owner's
`entering_phase_nine.ogg` reference.

`default_voice.wav` is the prior checked-in reference, now exposed as the Male
secondary preset. It is 13.009 seconds, 16 kHz mono PCM16, and contains no WAV
metadata tags.

Replace it only with a voice you own or have permission to clone. Keep voice
references short, clean, single-speaker, and free of music or strong room
reverberation. Do not commit user-uploaded or session-recorded references.
